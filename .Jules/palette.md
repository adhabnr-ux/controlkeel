## 2024-05-18 - Missing keyboard focus states on custom interactive elements
**Learning:** Found zero instances of `focus-visible` or explicit focus states within the `lib/controlkeel_web/components/` directory (prior to the fix in `command_pill.ex`). While some standard HTML elements might get default focus styling, custom interactive elements (like icon-only buttons for copying commands) lack clear visual indicators for keyboard navigation users. This is a critical accessibility issue because keyboard-only users rely on focus styles to know which element is currently active.
**Action:** When creating or modifying custom interactive elements (buttons, custom links, toggles), always explicitly add keyboard focus styles. Use `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary rounded` (or similar appropriate styles matching the design system) to ensure focus rings are visible when navigating by keyboard but remain hidden during mouse interactions.
